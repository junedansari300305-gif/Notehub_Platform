# 📚 NoteHub - Notes Sharing Platform

**NoteHub** is a web-based platform designed to make sharing, managing, and accessing study notes easier. It provides users with a centralized place to organize learning resources and connect with other students through communities.

## 🚀 Features

- **User Authentication:** User registration and login.
- **Notes Management:** Access and manage study notes.
- **Communities:** Connect and interact with other learners.
- **File Upload:** Upload and share documents.
- **User Profiles:** Manage user profile information.
- **About Section:** Information about the NoteHub platform.
- **Responsive Design:** User-friendly web interface.

## ⚙️ Installation & Setup

Follow these steps to run NoteHub on your local machine.

### 1. Clone the Repository

```bash
git clone https://github.com/junedansari300305-gif/Notehub_Platform.git
```

### 2. Open the Project

```bash
cd Notehub_Platform
```

### 3. Create a Virtual Environment

```bash
python -m venv venv
```

### 4. Activate Virtual Environment

For Windows:

```bash
venv\Scripts\activate
```

### 5. Install Dependencies

```bash
pip install -r backend/requirements.txt
```

### 6. Run the Application

```bash
python backend/app.py
```

Open the local URL displayed in your terminal (usually `http://127.0.0.1:5000/`).
